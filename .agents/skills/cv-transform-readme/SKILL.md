# Сборка резюме: README.md → index.html → PDF

## Шаги

1. Прочитай целиком `README.md` (корень репозитория) и `src/template.html`.
2. Собери `index.html` в корне репозитория: возьми шаблон **без изменений** и подставь данные из README вместо плейсхолдеров `{{...}}` (правила ниже). Справочный комментарий `<!-- СПРАВОЧНИК РАЗМЕТКИ … -->` в index.html **не включай**.
3. Запусти `npm run compile-pdf` — сгенерирует PDF из `index.html` (puppeteer). Если нет `node_modules`, сначала `npm install`.
4. Имя PDF скрипт выводит из README сам: заголовок `#` без отчества + роль до разделителя `·` — напр. `Бахарев Артём Senior Frontend Engineer.pdf`. Руками имя не задавай; если нужно разовое исключение — `node src/compile-pdf.js "Другое имя.pdf"`.
5. Если имя изменилось, скрипт в конце перечислит PDF со старыми именами — удали их (`git rm`, если файл в индексе) и поправь ссылку на PDF в блоке `<div class="hide">` в конце README (URL-кодированное имя файла).
6. Проверь результат: прочитай получившийся PDF (Read) и убедись, что ничего не поехало — секция «Опыт работы» начинается со второй страницы, блоки не разорваны, контент соответствует README.

## Правила подстановки

- `{{TITLE}}` — «Имя Фамилия — краткая роль», напр. «Бахарев Артём — Full-stack разработчик».
- `{{NAME}}` — заголовок `#` из README.
- `{{ROLE}}` — жирная строка-подзаголовок сразу после заголовка `#` в README (должность + 2–3 ключевые технологии, напр. «Ведущий Full-stack разработчик · TypeScript / React / NextJS»). Берётся из README как есть, без переформулирования; в блоки `.fact` эта строка не попадает — у неё нет двоеточия.
- `{{FACTS}}` — строки шапки README вида `**…:** значение` → блоки `.fact` с иконками (см. справочник в шаблоне). В длинных значениях ставь `&nbsp;` после однобуквенных предлогов/союзов (и, в, с).
- `{{CONTACTS}}` — контакты из шапки README → ссылки `.contact` (`tel:`, `https://t.me/…`, `mailto:`, github). Текст ссылки — без `https://`.
- `{{GOAL_TITLE}}`, `{{SUMMARY_TITLE}}`, `{{EXTRA_TITLE}}`, `{{EXPERIENCE_TITLE}}`, `{{PROJECTS_TITLE}}` — заголовки `##` из README (без иконок-картинок).
- `{{GOAL_TEXT}}` — текст секции «Цель» (абзац после заголовка): ключевые роли выделяй `<strong>`.
- `{{SUMMARY_ITEMS}}`, `{{EXTRA_ITEMS}}` — пункты списков секций «Кратко» и «Ещё» → `<li>`:
  - `` `код` `` → `<code>…</code>`;
  - ключевое (годы опыта, роли, названия) → `<strong>`;
  - голые URL → `<a>` с коротким текстом-доменом;
  - точки с запятой в конце пунктов убирай.
- `{{JOBS}}` — строки таблицы «Опыт работы» → блоки `.job` (образец в справочнике шаблона):
  - место работы без даты окончания → `class="job current"`, дата «с 01.2024<br>по наст. время»;
  - остальные даты: «03.2022 — 08.2023» (или просто год, если только он указан);
  - жирное начало ячейки → `.job-title` (должность) + `.job-place` («— Компания (город, примечания)»);
  - осмысленный текст описания → `.job-desc`; технологии, упомянутые внутри связного текста, оставляй как `<code>`;
  - перечень технологий → чипы `.job-tags` (`<span class="tag">`), в описании его не дублируй;
  - ссылка на компанию → `.job-link`, текст — чистый домен (для ссылок на web.archive.org — домен оригинального сайта).
- `{{PROJECTS}}` — пункты «Мои проекты» → карточки `.project` (name / desc / tags / links).
- Блок `<div class="hide">` в конце README (ссылки на PDF/веб-версии) и `<p style="break-after: page;">` в index.html не переносятся: разрыв страницы в печати уже задан стилем `.experience-section { break-before: page }`.

## Если README или дизайн меняются

- Новая секция в README → добавь `<section>` по образцу существующих и соответствующий плейсхолдер в `src/template.html`, чтобы шаблон не расходился с index.html. Иконка — инлайн SVG из Bootstrap Icons (`viewBox="0 0 16 16"`, класс `icon`).
- Просьбы поменять дизайн выполняй в `src/template.html`, затем пересобери index.html и PDF по шагам выше.
